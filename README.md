# 微信语音播报

收到微信新消息时，通过系统 TTS 语音引擎用扬声器自动播报，支持：文本、红包、转账、小程序、名片、文件、聊天记录、群名、群@提示、昵称备注、拍一拍、群成员变动、链接、口令、消息引用、问号、图片、视频、语音、表情、位置、视频号、歌曲、撤回24种消息类型。

## 功能

- 文本消息播报「xx说，内容」；媒体消息播报「xx给你发送了一张图片/一个视频/一条语音/一个表情/一个位置」…等等
- 歌曲消息播报「xx给你发送了一首歌曲，歌曲名是：《歌手的，歌名》」，提取不到时退化为「xx给你发送了一首歌曲」
- 表情消息播报前停顿 0.5 秒再播报（动画表情、普通表情均适用）
- 群聊转账收款播报「xx群，B接收了A的一笔转账」（B=收款人，A=付款人，解析不到回退「有人」）
- 排除自己发送的消息
- 白名单：只播报指定联系人和/或指定群聊（文本输入昵称/wxid，或从好友/群聊列表勾选）
- 免打扰时段：支持跨午夜区间（如 23:00-07:00）
- 语速可调（0.5-2.0）
- 播报发件人开关
- 串行播报队列，不打断前一条
- 设置页/白名单页/选择器统一圆角卡片式 UI：圆形头像、分组标头、胶囊搜索框、主题色按钮

## 设置入口（插件列表右侧设置图标）

| 菜单项 | 说明 |
| --- | --- |
| 白名单开关 | 可视 Switch 开关，点一下开、再点一下关；行末有小字"点击"提示，点击该行进入「白名单」二级页 |
| 修改免打扰时段 | HH:mm-HH:mm，支持跨午夜，留空关闭 |
| 修改语速 | 0.5-2.0 |
| 切换 播报发件人 / 总开关 | 确认=切换发件人，取消=切换总开关 |

「白名单」二级页：

| 菜单项 | 说明 |
| --- | --- |
| 好友（已加入 N 个） | 选择白名单好友：分组显示带头像，支持搜索，多选勾选保存；已选中的置顶并带✔标识（N 为已加入白名单的好友数，选择器标题显示好友总数） |
| 群聊（已加入 N 个） | 选择白名单群聊：仅群聊列表带头像，支持搜索，多选勾选保存；已选中的置顶并带✔标识（N 为已加入白名单的群聊数，选择器标题显示群聊总数） |

## 配置项（config.prop，可在插件设置入口修改）

| key | 默认 | 说明 |
| --- | --- | --- |
| enabled | true | 总开关 |
| whitelist_enabled / whitelist | false / 空 | 白名单开关；逗号或换行分隔的昵称/wxid |
| whitelist_contacts | 空集合 | 从好友/群聊列表勾选保存的 wxid 集合 |
| whitelist_groups | 空集合 | 从群聊列表勾选保存的群 ID 集合（配合 whitelist_contacts 任一命中即播报） |
| quiet_enabled / quiet_start / quiet_end | false / 23:00 / 07:00 | 免打扰时段 HH:mm-HH:mm，支持跨午夜 |
| voice_rate | 1.0 | 语速 0.5-2.0 |
| say_sender | true | 是否播报发件人 |
| group_name_enabled / at_only_enabled | true | 群聊带群名播报 / 群聊仅@时播报 |
| continuous_enabled | true | 连续播报时，前缀播报30秒刷新：30秒内同群/同发件人消息省略前缀，关闭则每次完整播报 |
| text_enabled / image_enabled / video_enabled / voice_enabled / emoji_enabled / location_enabled / finder_enabled / music_enabled / recall_enabled | true | 各消息类型播报开关 |
| max_text_len | 80 | 文本播报最大长度 |

## 使用

1. 在 Hchat 中启用本插件
2. 确认系统已安装 TTS 语音引擎（设置-辅助功能-文本转语音）
3. 播报音量跟随媒体音量

依赖接口：`onLoad` / `onHandleMsg` / `openSettings`，消息对象 getter，`getFriendName` / `getFriendDisplayName`，`showModule*Dialog` 系列弹窗，配置读写方法。
